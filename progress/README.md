# DevOps Learning Progress Tracker

This folder tracks my daily and weekly progress while preparing for
DevOps / Cloud Engineering roles.

## Purpose
- Maintain consistency
- Track real learning progress
- Build interview-ready proof of hands-on work

## How I use this
- `ROADMAP.md` → Overall learning plan
- `DAILY_LOG.md` → Daily work log
- `WEEKLY_REVIEW.md` → Weekly reflection & improvement

> Progress is tracked via GitHub commits and markdown updates.
